# 🐶 Lovey Doggy

반려견 보호자들이 자유롭게 이야기를 나누고 소통할 수 있는 커뮤니티 서비스입니다.

## Front-end 소개

- Vanilla JavaScript를 기반으로 커뮤니티 웹 서비스를 구현했습니다.
- Spring Boot REST API와 연동하여 회원, 게시글, 댓글, 좋아요 기능을 구현했습니다.
- 제목, 제목 + 내용, 작성자 기준의 게시글 검색 기능을 구현했습니다.
- 최신순, 조회수순, 좋아요순 정렬과 커서 기반 무한 스크롤을 적용했습니다.
- 회원가입 시 랜덤 기본 프로필 이미지를 제공하고, 프로필 이미지 변경 시 미리보기를 지원합니다.

## Back-end API 연동

Spring Boot 기반 REST API와 연동하여 서버의 데이터를 화면에 반영하고 사용자 요청을 처리했습니다.

- 프로필 및 게시글 이미지 URL 처리

## 주요 개선 사항

### 게시글 목록 무한 스크롤

게시글을 한 번에 모두 불러오지 않고 커서 기반 페이지네이션 API와 연동했습니다.
사용자가 목록 하단에 도달하면 다음 게시글을 조회하여 기존 목록에 이어서 표시하도록 구현했습니다.

### 게시글 검색 및 정렬

검색 유형과 정렬 조건을 쿼리 파라미터로 전달하여 제목, 제목 + 내용, 작성자를 기준으로 게시글을 검색할 수 있도록 구현했습니다.
또한 최신순, 조회수순, 좋아요순 정렬과 최근 7일 기준의 주간 인기글 조회를 지원하도록 구성했습니다.

### 게시글 목록 위치 유지

무한 스크롤로 게시글을 탐색하던 중 상세 페이지에 진입한 뒤 목록으로 돌아왔을 때,
기존 목록과 스크롤 위치를 복원하여 사용자가 조회하던 지점부터 계속 탐색할 수 있도록 구현했습니다.

### 프로필 이미지 처리

회원가입 시 랜덤 기본 프로필 이미지를 제공하고, 프로필 이미지 변경 시 업로드 전에 선택한 이미지를 확인할 수 있도록 미리보기 기능을 구현했습니다.
서버에서 전달받은 이미지 URL과 기본 프로필 이미지를 공통으로 처리하여 화면에 표시하도록 구성했습니다.

## 프로젝트 후기

Vanilla JavaScript로 화면을 구현하고 Spring Boot REST API를 직접 연동하면서 프론트엔드와 백엔드 사이의 데이터 흐름을 이해하는 데 집중했습니다.

특히 게시글 검색·정렬, 커서 기반 무한 스크롤, 좋아요와 댓글 등의 기능을 구현하면서 API 요청과 응답에 따라 화면 상태를 처리하는 경험을 할 수 있었습니다.

또한 로컬 환경뿐만 아니라 실제 배포된 백엔드와 연동하면서 개발 환경과 운영 환경의 차이를 경험했고, 프론트엔드 개발에서도 서버와 배포 환경을 함께 고려해야 한다는 점을 배울 수 있었습니다.
